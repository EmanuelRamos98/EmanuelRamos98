## 📂 Proyectos Destacados

### 💬 Warap
Aplicación de mensajería en tiempo real inspirada en la interfaz y funcionalidad de WhatsApp. 
* **Características:** Sistema completo de gestión de usuarios (Alta, Baja y Modificación) y envío/recepción fluida de mensajes.
* **Stack:** `React` `Node.js` `Express` `MongoDB`

### 📅 GesTurno
Plataforma integral diseñada para la gestión, control y asignación de turnos a clientes.
* **Características:** Optimiza la agenda del negocio, permitiendo un seguimiento ordenado de las citas y mejorando la atención al cliente final.
* **Stack:** `React` `Material UI` `Node.js` `Express` `MongoDB`
